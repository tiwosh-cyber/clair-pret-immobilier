# Questions produit à remonter au propriétaire (Notion)

Pour le projet Clair, ce fichier transmet les décisions produit ouvertes de Claude Code (phases 07–08) au propriétaire et à la source de vérité Notion. Claude y ajoute une ligne quand une décision produit manque, est ambiguë ou se contredit entre deux documents. Il ne tranche jamais à ta place.

**Comment l'utiliser :**
1. Tranche les questions `OUVERTE`.
2. Fais valider la décision dans les pages Notion existantes du projet, puis mets à jour les Markdown de passation concernés.
3. Remplace les documents dans ce dossier, passe la question en `RÉSOLUE` et indique la décision.
4. Relance Claude sur le lot bloqué.

Statuts : `OUVERTE` (bloque le lot indiqué) · `RÉSOLUE` · `ABANDONNÉE`. Seules les lignes du tableau ci-dessous comptent ; il est vide tant qu'aucune question réelle n'existe.
